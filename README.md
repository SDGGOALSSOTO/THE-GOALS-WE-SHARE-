# The Goals We Share

An inclusive, responsive guide to all 17 Sustainable Development Goals, their connections to shared values, and their benefits for society.

Includes a cinematic opening scene, a rotating particle globe, interactive goal cards, search and theme filters, animated detail panels, and reduced-motion support.

Open `index.html` in a browser to view the website. The site has no build step or external runtime dependencies; keep `effects.css` and `effects.js` beside the HTML file.

Content references: [UN Sustainable Development Goals](https://sdgs.un.org/goals) and [2030 Agenda](https://sdgs.un.org/2030agenda). Goal-to-value connections are educational interpretations.
